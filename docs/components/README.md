# Components

Documentation for DOSage components.

## Categories

- **Layout** - Container, Panel, Box, Grid, Divider, Separator
- **Typography** - Heading, Text, Code, CodeBlock, List, etc.
- **Form Controls** - Button, TextInput, Checkbox, Select, etc.
- **Feedback** - Alert, Toast, ProgressBar, Spinner, etc.
- **Navigation** - Menu, Tabs, Breadcrumb, Pagination
- **Data Display** - Table, Card, Badge, Avatar
- **Overlays** - Window, Dialog, Popover
