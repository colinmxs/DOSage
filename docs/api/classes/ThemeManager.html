    Class ThemeManager

    ThemeManager provides static methods for managing DOSage themes.

    Example

    // Set a preset theme
    ThemeManager.setTheme('amber');

    // Get current theme
    const current = ThemeManager.getTheme();

    // Register a custom theme
    ThemeManager.registerTheme('my-theme', { ... });
